# AI 反馈闭环技术栈选型

## 要做什么

研究浮之静文章《技术栈推荐：围绕 AI 反馈闭环做选型》（公众号：浮之静）：核心主张=AI agent 开发的技术选型应围绕『缩短 agent 从修改代码到获得有效反馈的周期』+『用明确工程约束提高结果可验证性』。
三层结构：① 原生化工具链降低反馈延迟——pnpm v12（Rust 原生）、TypeScript v7（编译器迁 Go）、Vite v8（Rolldown+Oxc）、Oxlint+Oxfmt，降低高频执行验证命令的固定成本；② 类型与检查系统提供可执行证据——TS 类型契约 + Oxlint 诊断 + 格式化，错误输出带文件/位置/规则/原因，结构化反馈让 agent 少靠模型推测；③ Agent Skills 约束过程与质量——lencx/skills（keel 架构治理 + coding-protocol 按风险分级执行协议）、mattpocock/skills（需求澄清/TDD/复现诊断/代码审查）、Impeccable（UI/UX 审查），组件层配 Astryx（Meta 开源，CLI 提供机器可读组件文档供 agent 检索）。
