# 配置 X 书签访问通道

## 要做什么

目标：让 Hermes 通过官方 xurl 技能读取松海自己的 X 账号书签。

前提：
- 需 X 开发者账号 + OAuth 2.0 用户访问令牌（含 bookmark.read、tweet.read、users.read 等 scope）
- 书签是私有数据，仅支持用户上下文认证，不能用应用级 Bearer Token
- X 自 2026-04 起对 Owned Reads（自身数据读取，含书签）降价，单次约 $0.001
- Hermes 的 Grok OAuth（X Premium+）不直接支持书签读取，仍需独立配置 xurl

设置步骤：
1. 安装 xurl：curl -fsSL https://raw.githubusercontent.com/xdevplatform/xurl/main/install.sh | bash；验证 xurl --help
2. 前往 console.x.com 创建 Project 与 App（生产环境，Public Client）
3. 本机完成 OAuth 2.0 Authorization Code with PKCE 认证（必须松海本人操作，Client Secret 不交给 Agent）：
   xurl auth apps add my-app --client-id <ID> --client-secret <SECRET>
   xurl auth oauth2 --app my-app
   xurl auth default my-app
   xurl auth status
   xurl whoami
4. 在 Hermes 中确认 xurl 技能已加载且认证有效
5. 测试自然语言读书签（例："获取我的最近 100 条书签" → xurl bookmarks -n 100）

进阶（可选）：
- Awaek 技能：书签转可对话本地知识库（SQLite 索引 + 语义搜索），安装后运行 Awaek sync
- x-bookmarks-kindle-digest：书签整理成 Kindle 电子书
- bookmarkmaxxing：自动摘要与分类
- 支持分页、文件夹管理、添加/删除书签

注意事项：
- 认证必须在本机由松海手动完成，安全优先
- 速率限制：书签查询约 180 次/15 分钟
- 仅支持读取自身账号书签；公开搜索走 Hermes 的 x_search 工具（基于 Grok OAuth）
