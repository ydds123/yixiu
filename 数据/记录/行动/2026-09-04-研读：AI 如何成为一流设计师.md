# 研读：AI 如何成为一流设计师

## 要做什么

Lenny「s Newsletter 客座文章（作者 Anshu Chimala，前 Apple 12 年软件工程与设计团队负责人，研发未来 AI 产品原型；2026-09-01，付费文章）。

核心论断：LLM 是 next-token 预测器 + 人类反馈训练，每一步都填「最可能取悦所有人」的 token → 默认产出是设计委员会式平庸；一流设计是感受驱动、情绪回应、打破规则，与模型天性相反。多数人只触到 AI 创造力 1%，方法是引导模型走出最可预测的选择。

三阶段框架（类 Double Diamond，适用于 AI agent 团队）：
一、Discover 探索空间：先广后深。
1. 种子串注入多样性：给 4 个实例同一 prompt 得到千篇一律紫色渐变左文右图；换大胆命题（像素游戏定格感 / 等距 3D 城市 / 激进不对称破规则）即出独特方向。
2. 生成想法也要人筛：让 AI 列「故意缺细节」的宽泛想法清单 → 自己 visualize 挑方向并记录感受 → 让 AI 按你的口味细化 → 最后让它写 POC prompt。主动 steer 才能得到只有你能做出的东西。
3. 敢试「听起来必烂」的方向；失败的 prompt 存档，新模型发布后再测。
二、Define 深化方向：种子串结果仍套旧布局模式。
4. 子代理正反馈循环：coding agent 自审不客观，另设「设计评论家」子代理——只看截图不看实现、新鲜上下文、客观基准（5 张里 4 张专业参考 + 1 张我们的，按打磨度排序打分）、停在第 9/10 分且停止标准谨慎（防烧 token）；大模型当评论家做裁决（占输出 token <10%），便宜模型干粗活——成本分层。
5. 图片生成注入个性：coding agent 默认用渐变/形状/基础图案（AI 味重灾区），明确指示用图像生成（Codex/Antigravity 内置、ChatGPT 订阅走 Codex CLI、或专用限额 API key，密钥放 gitignore 文件）。
6. 视频生成做动效：loop 片段 + 绿幕/视频抠像叠加进 UI（玻璃折射先烘到背景再抠）；关键帧插值做页面间转场、随滚动擦洗（fal.ai 聚合 + Seedance 2.5 类强物理模型）。
三、Deliver 打磨交付：
7. 减法优先：AI 只加不减，多余元素/过度解释是最大 AI 味；克制即高级（卡路里 App 案例：去掉粉光晕/随机高亮/多余标签 → 苹果原生感）。
8. 去掉 AI 痕迹（正文付费墙后，未读）。

案例：对话式卡路里追踪器 3 prompts（Claude Fable 5）、太空探索游戏 2 prompts（Claude Opus 5）、动态落地页 3 prompts（Claude Opus 5 + GPT-5.6 Sol）。
