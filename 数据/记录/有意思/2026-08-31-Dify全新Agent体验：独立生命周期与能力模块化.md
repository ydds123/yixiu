# Dify全新Agent体验：独立生命周期与能力模块化

## 保存内容

Dify 全新 Agent 体验：Agent 从工作流执行节点升级为独立生命周期实体（独立构建/调试/发布/管理，Web App、API、Workflow 灵活接入）。能力模块化——Prompt 只定义角色与行为边界，Skills（团队方法沉淀）、Tools（长期正式能力）、Sandbox CLI（临时需求）各司其职。Build 从真实任务打磨能力，Manage 一处构建随处复用（Agent 决定会什么，Workflow 决定做什么），Track 三层观测（单次追溯/节点流转/长期指标）。核心：让修正成为下一次运行的起点，把运行中发现的问题转化为对知识、规则或 Skill 的调整。
