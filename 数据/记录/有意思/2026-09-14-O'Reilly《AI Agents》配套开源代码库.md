# O'Reilly《AI Agents》配套开源代码库

## 保存内容

**是什么**：O'Reilly《AI Agents - The Definitive Guide》整本书的配套代码，作者全部开源在 GitHub（Nicolepcx/ai-agents-the-definitive-guide，2k+ star）——12 章、35 个 Jupyter Notebook，每个都有 Colab 入口，浏览器点开直接跑，不用本地装环境。
**覆盖**：思维链、思维树、ReAct 等经典 Agent 模式 → 多 Agent 协作、记忆管理、效果评估、成本计算；最后一章专讲 Agent 系统威胁建模（工具权限控制、Prompt Injection 防护、危险操作处理）。
**用法**：入门可当完整学习路线；在做项目时挑薄弱部分单看。松海留作后面做 AI 智能开发时的参考，到时候可以找 Hermes 问。
