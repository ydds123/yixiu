# 本机 Agent 靠近我，云端 Agent 离开我

## 核心观点

个人 AI 的最小可用形态，是一个靠近我的中枢加一个触点：中枢能碰到我的数据、登录和真实环境，触点是随时能找到它的消息通道。云端 Agent 不是必需的第三颗星，而是按需加上的「分身」。它离开我，跟我的真实环境隔开，能放手试错，也能同时开很多个。协同就是让分身在隔离环境里先做，再把成果交回中枢，由我认领。

## 论据

「我是否在场」不是本质区别：Mac 常开也能跑定时任务，借飞书这类云上消息平台，我在外面也找得到它。只有云端能提供的，是一台弄坏了也无所谓的机器。X 上的用法也印证了这一点：有人看重本机的磁盘级上下文，有人看重云端能放手又不危及个人文件。

也有限制。本机也能套沙箱；对没有常开电脑的人来说，「合上电脑也能继续跑」会让云端变成必需品。中文圈还有人把云端当成更稳定的身份来防封号。以上是基于一天体验和少量案例的工作假设。

## 关系

这张卡回应的问题是：一件 AI 工作该放本机、云端，还是两边协同。适合在搭个人 AI 架构、设计定时任务、评估新 Agent 产品时调用。它和 GoodIdea 的「最小产品形态是 Skill」思路相近，都是先找一个不能再缩减、但仍然完整的最小单位，不过这只是相似，不是依据。它还留下一个开放问题：有哪些事，我以前因为怕弄坏真实环境、或者一个人忙不过来而没做？
