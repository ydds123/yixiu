# 为什么Muse团队做出了ChatGPT以来增长最快的AI产品？

> 作者：深思圈
> 发布日期：2026-10-13

你有没有想过，当整个 AI 行业在 2026 年初几乎被一个共识统治——coding agent（代码智能体）才是唯一重要的 AI 形态——有一家公司偏偏往相反的方向走了，七个月后交出了据称是 ChatGPT 以来增长最快的消费级 AI 产品？Scale AI 的创始人、现 Meta 首席 AI 官 Alexandr Wang 在 David Senra 主持的播客 Founders Daily 里，把 Muse 诞生的完整过程讲了一遍。Wang 自己在访谈开头说，他现在觉得过去这几周是他职业生涯里最快乐的一段时间——这种话通常意味着那个人真的做到了什么他很长时间以来一直想做的事。

这期访谈发布在十月中旬，Wang 主要讲了五件事：为什么押注个人 agent（个人智能体）而不是 coding agent；从两周的原型到正式发布，七个月里发生了什么；为什么好的消费级 AI 产品只能有“一个观点”；Muse 是怎么增长起来的；以及从创办 Scale AI 到加入 Meta 重建一个 AI 实验室，他对“管理”这件事的认知发生了什么变化。访谈里涉及具体数字的地方，我会说明是否有外部来源。我有不少自己的想法，整理出来和大家聊一聊。

## 全行业跑向 coding agent，他们往另一边走了

先说背景。2026 年初，Claude Opus 4.5 的发布，让 coding agent 这件事从一个可能性变成了一场运动。Wang 在访谈里说，那时候整个行业对 coding agent 有种近乎强迫性的聚焦，conventional wisdom（业界共识）是 coding agent 是唯一重要的 AI 形态，“有一种强烈的引力要把所有人都拉去做 coding agent，和 Anthropic 正面竞争”。这种力量是真实的——Anthropic 那时候在 coding 上领先所有人，也在整个行业爆发。

让 Wang 和 Natt Friedman 走向另一边的，是同年 2 月的一段亲身经历。Friedman 用 OpenClaw（一款早期个人 agent 工具）写了一套多轮深度心理探查的提示词，Wang 第一次用了之后，把那次体验形容为“大概等于三年的心理治疗压缩在一个时刻”。他说自己当时非常脆弱，但同时也感受到了“魔法”。此后几周，两个人几乎把所有空闲时间都花在和各自的 OpenClaw 对话上，试图搞清楚个人 agent 到底能做什么。

但这还不够解释为什么是 Meta 来做这件事。Wang 说，他在正式加入之前就告诉 Mark Zuckerberg 一件事：AGI 时代的承诺是我们不再把时间花在“不得不做的事”上，而是花在“想做的事”上。Meta 旗下的产品——Instagram、WhatsApp、Facebook——恰好覆盖的就是“想做的事”那一层：兴趣、朋友、生活里自己关心的人。这让 Meta 在消费级 AI 上有一个别人没有的优势，不是技术，而是它三十年来积累的，就是人类欲望的入口。coding agent 帮你完成工作，个人 agent 帮你过上你想要的生活——Wang 的判断是，这是两件不同的事，而 Meta 被设计来做后者。

## 个人 agent 架在刀刃上：它要么让人惊艳，要么就是垃圾

Wang 用过一个说法，我觉得抓到了这个产品类别最真实的挑战：personal agents rest on a knife's edge（个人 agent 架在刀刃上）。如果能可靠地带来魔法时刻，它有成为有史以来最伟大消费产品之一的潜力；但如果体验不可靠，人们就会觉得它是垃圾。没有中间地带。

OpenClaw 本身就是前车之鉴。它在 2026 年初曾经点燃过一波热情，后来就消失了。Wang 的判断是，原因不是概念错了，而是体验没有打磨到位——有魔法时刻，但大多数时候不可靠，“峰值很高，平均值很低”。这也定义了接下来七个月的核心工作：不是往前探边界，而是把已知的体验从“有时候很好”做到“绝大多数情况下都很好”。

具体做法，Wang 描述的是一张超过一百项特定行为和能力的表格，每一行都有门槛：什么叫 launch blocking（阻塞发布），什么叫 good（够了）。他们持续迭代模型，持续测试，每次回来看这张表找到还是红色的再改。有很多检查点是 80 行绿了、20 行还是红的，他们知道那不够。第一个全部过绿的模型检查点出现，才有了正式发布。整个团队，包括模型工作在内，不到 200 人。Wang 说，所有高管都知道这是今年最重要的产品，但他们有意克制，没有让团队膨胀，因为他们知道这必须是“一件作品”。

## 一件作品只能有一个观点——产品版弗兰肯斯坦是怎么来的

Wang 在访谈里讲了一件大公司做产品经常发生的事：每个 PM 都有一件事想塞进来，全部混在一起，变成一个 Frankenstein（弗兰肯斯坦）式的大杂烩。用户能感受到——你能感受到这个产品明显有几组不同的人在不同的信念下做的，然后他们只是把东西拼到一起。他还有个形容：这是 “PM 地狱”，每个产品想法都被混进去做成一杯奶昔。

Muse 要的是完全相反的东西：一个清晰的视角，一个完整的体验。Wang 明确说，如果 Muse 有一个人的视角贯穿始终，那个人是 Natt Friedman，他的品味和判断定义了产品最终的样子。访谈是在 Jobs 去世 15 周年那天录的，David Senra 提到了那句描述 Apple 的话：Apple is just Steve Jobs with 10,000 lives，产品就是他的品味、他的观点、他想看到的世界。Wang 说，Friedman 对于 Muse 的作用与此类似，这不是谦虚，是他对 Muse 能做到现在这个样子的解释。

我认为这是 AI 产品时代一个很容易被低估的判断。大家都在问哪个模型更好，哪个功能更多，但 Wang 的意思是：谁能把复杂性消化在内部，对外只呈现一个连贯的体验，那个人才是赢家。小团队的优势不只是效率，而是它结构性地更容易保住那个“单一视角”。

## 用梗图破圈，靠截图传播——但前提是产品能接住

Muse 在 X 上的早期传播，有很大一部分来自 Wang 本人。他说那段时间自己处于一种近乎着魔的状态，在开会时脑子里突然闪过一个梗，不得不发出来，“感觉像一个工程师又开始解决 bug 了，能感受到什么时候会对”。他后来意识到了一件关于互联网的事：互联网奖励风险，奖励出人意料，而他用的 Jolly 吉祥物——Muse 产品里的那个卡通角色——可以被放进各种场景里，这给了他很多发挥的空间。

但 Wang 在访谈里顺带批评了 Anthropic 和 OpenAI 的户外广告活动，说它们都是关于品牌本身的，没有人关心你的品牌或者你的研究，人们只关心它能为他们做什么。他引了一本 20 世纪初写的广告学书《Scientific Advertising》里的核心判断：你的广告不应该是关于你的，应该是关于它能给用户做什么，这个道理一百年前就写出来了，但大家还是不断犯同一个错误。

比梗图更重要的是截图。Wang 举了一个例子：一个管理着巨额资金的朋友把 ID 遗忘在私人飞机上，告诉 Muse “我不想参与任何环节，你去搞定它”，Muse 联系了快递，沟通了安保，最后把 ID 送回去了。这件事的三四张截图，任何人看了都能立刻理解这个产品在做什么，不需要任何解释。Wang 说，这是最好的营销——他意识到 Muse 产品本身的截图天然适合传播，一部分原因是那个吉祥物让人一眼认出这是 Muse 的截图，“这是你能得到的最好的品牌标识”。

这些都只是让人下载。Wang 也讲了让人留下来的机制：用户和 agent 之间有一个 trust fall（信任递进）的过程。先给它一个小任务，完成了再给大一点，再完成了再给更大的，每一步都是在测试边界，也在建立信任。那些离开的用户，大多是在这个过程里某一步摔了。他说，凡是真正爱上 Muse 的用户，都经历了这个递进——从“我给它一个小事做做”，到“我把这件很重要的事交给它处理”。

## 他离开了做了九年的公司，去接手一个需要重建的实验室

Scale AI 是 Wang 19 岁创办的，他做了九年。Mark Zuckerberg 在 Llama 4 未能达到预期之后联系到他，最初只是问“你觉得我们应该怎么做”，后来演变成一笔他自己都形容为“疯狂”的交易：Meta 持有 Scale 49% 的股份，Scale 继续运营，Wang 和几位同事加入 Meta。整个从第一通电话到确定交易，大概五六周。

Wang 在访谈里说，他当时的第一反应是：这大概是真的，但可能也说不通。他把自己和 Scale 的关系描述为，真的把它当成了 life's work（毕生事业），所以那个情感过程并不容易。但最终让他决定的，是两件事放在一起：这个交易结构对 Scale 的所有股东来说确实是一笔好交易，Scale 本身可以继续；而 Meta 这一边，正是因为当时“看起来很糟”，反而为他创造了从头建起一件东西的条件。

我认为这里讲了一个不常被说清楚的判断标准：一个地方吸不吸引人，不只取决于它现在有多好，还取决于它现在有多少待填补的空间。当 Meta AI 看起来需要被重建的时候，它对一个有想法的人来说反而是最诱人的处境——方向还没定，团队还没搭，原则还可以自己写。

## 钻石矿和摩天楼是两种工作，他在 Scale 做一件，在 Meta 做另一件

Wang 用来区分这两段经历的框架，我觉得适用范围很广。他说有两类工作：摩天楼建设（skyscraper building）和钻石矿开采（diamond mining）。

摩天楼建设是 payoff 相对线性的工作：你有一个流程，把它做到极致，一点一点提升效率，0.5% 的改进就是 0.5% 的价值，全靠把每一个细节优化到极限。Scale AI 做数据标注，就是这类工作——规模大，复杂，但逻辑是线性的，最重要的能力是流程管理和效率压榨。

钻石矿开采是 payoff 有幂律分布的工作：大多数事情没有价值，但其中某一件可能比其他所有事情加起来还有价值一百万倍。VC（风险投资）是典型例子，AI 研究也是。Wang 在 Meta MSL 的工作是这种逻辑——他对 200 多个直接下属的解释是：这是一个反官僚主义的姿态，这些人都是顶尖的研究员，不需要被管，他们需要的是空间和资源。他说自己的角色更像是“优质环境的守护者”，而不是直接的管理者。

这个框架的真正价值，在于它指出了一个管理上最容易犯的错误：用摩天楼的方式管一个钻石矿，是最快扼杀一个研究团队的办法。你把所有人都逼着优化已知的流程，那些最有可能发现一件价值无比大的事的人，第一个离开。

## 我自己的一点思考

听完这期访谈，我最大的感受是，Wang 讲的这个关于 Meta 独特性的判断，值得反复想。他的意思不是 Meta 有更好的工程师，或者更多的钱，而是：Meta 做了三十年的事情，覆盖的恰好是人类欲望的那一层——人们想做的事，而不是不得不做的事。这在 AI 时代是一个真实的竞争优势，因为个人 agent 的价值，取决于它帮你做的那些事对你有多重要。帮你写代码，是帮你完成工作；帮你和重要的人保持联系、帮你追求自己真正在意的事，是另一类事。

不过要读出这期访谈的边界。Wang 是做这个产品的人，所有对 Muse 的描述都是内部视角。“ChatGPT 以来增长最快的消费级 AI 产品”，Wang 转推了一些第三方的图表来隐性暗示，但没有披露具体数字，也没有说清楚按哪个指标算。Muse 有多少活跃用户，留存是什么水平，这些都没有公开。OpenClaw 本身的历史也提醒了一件事：个人 agent 可以快速吸引早期用户，但留存是另一道关。

访谈最后，Wang 说了一句让我记住了很久的话：世界到目前为止，是由少数那些“不知怎么找到了把自己的欲望变成现实的方法”的人塑造的，但我们从来没有见过全人类每一个人的 agency（行动力）都被完全打开是什么样子。他说 Muse 代表的是这件事的开始，给每个人一个能够实现他们在童年时梦想的那种成年生活。这个愿景未必能实现，但作为一个方向，比“做一个更好的聊天机器人”深刻得多。
