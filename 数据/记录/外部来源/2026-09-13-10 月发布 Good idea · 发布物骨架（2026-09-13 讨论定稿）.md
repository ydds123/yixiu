# 10 月发布 Good idea · 发布物骨架（2026-09-13 讨论定稿）

## 三、第 5 格内容：整体架构

直接排开框架本身，不用叙事连接词：

定位 → 目标 → 结构 → 流转 → 节点 → 网络 → 治理 → 协作 → 演化 → 共创前提，收底于三个贯穿性主张。

- **定位**：不叫知识管理——是"借助大语言模型增强个人判断与行动能力的认知系统模式"；最终目标不是建立结构完整、关系丰富、维护完善的知识管理系统
- **目标**：目标函数 NCV = EV − C（EV = 机会×可找到性×有效性×可理解性×可应用性×结果贡献；C = 生命周期成本；约束 = 有限认知预算）；最终目标是认知价值循环：现实任务 → 找回过去材料 → 参与本轮思考 → 改变/加强/限制判断行动 → 完成任务 → 只沉淀真正值得的 → 再被调用；反目标：卡片数量、元数据完整度、网络复杂度、架构理论完整性都不是目标
- **结构**：五空间（闪念=认知激活事件／溯源=外部世界说过什么／有意思／待办／永久四类卡）；七层（内容／协作／执行／阅读=认知现场／内部／资产／历史）；权威顺序 AGENTS 宪法 > schema 契约 > Skills 流程 > README > baseline
- **流转**：来源快照+保存动机 → 闪念 → 连接思考 → 永久卡候选 → 真实来源连接+确认 → 接纳入网 → 行动反馈；身份四分（已确认认识／既有表达／外部来源／AI 本轮推演）必须始终可辨认；人=动机、判断、确认、行动，AI=预读、提问、审查、整理，CLI=确定性写入
- **节点**：永久卡 = 最小可复用的充分思维单元；五项必要条件（完成认知转化／一个中心判断／脱离语境独立理解／最低充分／进入未来任务）；准入顺序：先卡片合格、再网络激活，缺一不接纳
- **网络**：三过程 唤起→参与→重组；三机制 稳定身份／发现入口／语义关系；标签不是分类，是未来的使用场景；结构自下而上生长
- **治理**：生命周期 = 节点治理＋网络治理＋低摩擦＋真实使用反馈回路；整理卡片的目的不是打造博物馆，是解决问题、支持行动、服务写作；待办 48h 行动窗口＋估价机制；铁律：问题先发生，机制后产生；默认不制造维护工作
- **协作**：Skill = Trigger + State Machine + Resource Routing；两条正交轴（加载轴三级渐进披露＋权威轴每条事实一个 owner）；闪念状态机六步 接住→定位→找料→展开→校验→落盘；深度由规模×充分度四象限决定；维护门禁四关 Trigger Lab → Boundary → Context Budget → Output Lab
- **演化**：一期只闭合最小任务调用循环（召回→解释召回→身份区分→临时工作集→用户采用/拒绝→允许零沉淀干净结束）；其余进问题池，由真实失败触发才立项，不预设 roadmap；十项不可动摇原则（作者权／来源分离／身份清楚／永久化非前提／选择性沉淀／临时组合≠长期关系／确认门禁／确定性执行／问题先行／不制造维护）
- **共创前提**：用户焦点是 Agent 的输入起点（60 秒时效、冲突时以表达为准）；焦点是阅读层→协作层的层间接口
- **三个贯穿性主张**：① 知识库问"放哪"，卢曼问"和什么发生关系"，这套问"未来任务出现时，它能不能重新活过来"；② 让 AI 使用方法不是换执行者，是把方法从依赖人性默认重铸为依赖显式机制；③ 答案可以越来越容易获得，人的判断却不一定因此变得更好

## 四、第 6 格内容：业务流程与使用场景

**流程一 · 认知怎么流进来**：外部材料 → 存原文快照（外部世界说过什么）＋说明保存动机 → 闪念（认知激活事件，不是要点摘抄）→ 把若干念头连起来思考形成判断 → 判断合格（用自己的语言、一个中心判断、脱离语境能读懂、最低充分、未来会被调用）成为候选 → 接上可追溯的形成来源并确认 → 正式接纳入网 → 之后被唤起、参与新任务、被修订或退役

**流程二 · 任务怎么把过去调回来**：真实任务出现 → 召回可能相关的材料（永久卡、闪念、来源都算，不必先升级成卡）→ 每条说明"为什么召回它" → 四种身份始终分开 → 形成只服务本次任务的临时工作集，可采用、拒绝、纠正 → 任务结束后允许零沉淀、干净结束；只有明显值得长期复用的才回到流程一正式沉淀

**人机分工**：判断、动机、确认、行动是人；预读、提问、审查、整理是 AI；写入、事务、索引、回滚是 CLI——每一步可审计、可回滚

**它已经在跑（六周的账）**：22 份来源快照、26 条闪念（3 条待处理）、21 张永久卡、11 条有意思、30 条待办；卡片之间已有真实连接；后台每天自动维护（估价、过期扫描、索引与校验）

## 五、第 7 格内容：回到"还未诞生"（发问的一章）

- **前提承认**：现在做的所有事情，都还只是一种假设，是一个探索、验证的过程；而这个问题本质上也是很多人在思考的问题
- **主问句（定稿）**：人脑记不住、会忘、注意力有限，所以人一直在借工具往外挪（结绳、文字、笔记、知识库）；现在 AI 强大到能接住整条路，于是真正的问题是——我们是否具备一种能力，能够充分调用它。调用得动，它就能把偶发的好想法变成系统性的产出；调用不动，那还是瞎猫碰死耗子
- **调用的前提是缝合**：存下来的东西要和人的知识结构连上，否则它记着、人记不得，等于没存；这件事不太像查资料，更像是给思考造一个外脑——就像卢曼说的，思考时其实是在和笔、和卡片盒对话，得到一个让我们觉得是好想法的东西：把这件事的随机性转化为系统性的东西
- **诚实保留**：召回策略本身还有很多讲究和做法（比如 RAG 的各种路线），只是在一个方向上探索，这个方向和场景都还可以再细分
- **答不出来的问题（原样列）**：更完整的形态应该是什么？这件事的本质是什么？人和 AI 应该是什么关系？怎么构建、怎么玩——中间的设计理念、哲学理念和设计细节
- **收口方式**：收口放在问句上；最小 Demo 放在问句之前当锚点
