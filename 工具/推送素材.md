# 推送素材.py

主动推送闪念的**确定性素材层**。脚本只负责扫描、打分、组装上下文、只读拉取、记日志、定时段；挑哪张、怎么写由苏格判断（写法见 `数据/记录/行动/2026-10-14-主动推送闪念：从《保持饥饿，很难！》到满分样稿.md`）。

Python 3 标准库，输出均为 JSON。路径均相对 `数据/记录/`（也接受绝对路径、相对仓库根的路径或文件名）。

## 子命令

| 命令 | 作用 |
|---|---|
| `scan [--days 14] [--by both\|name\|mtime]` | 列出 闪念／原始思考记录／行动／外部来源／永久卡片／有意思 中，文件名日期或修改时间落在窗口内的记录（标题、status、topics、path、命中方式）。若大量记录仅因同一天的 mtime 命中，会给出 `warning`（如 10-14 迁移到云电脑导致 130 条 mtime 被刷新），此时用 `--by name`。 |
| `pool [--top 3]` | 待辨析闪念候选池（只取 `status: 待辨析`，排除发酵中等；排除最新摘要「已落下」里的卡）。打分见下。 |
| `context <卡片> [--cap 6000]` | 卡片全文（最多占 cap 的 60%）＋被链接或同日期的原始思考记录摘录＋1 跳出链／反链（标题＋前 ~300 字），总字数不超过 cap。 |
| `external [--days 14] [--limit 50]` | 只读拉取：微信读书（`/shelf/sync`、`/user/notebooks`、`/book/bookmarklist`、`/review/list/mine`，需 `WEREAD_API_KEY`）与得到大脑（`getnote notes -o json --created-from`）。存到 `数据/摘要/外部拉取/YYYY-MM-DD.json`。任一来源失败只记入 `errors`，不中断。不调用任何写接口。 |
| `log <卡片> --reaction <文本>` | 追加一行到 `数据/摘要/推送日志.jsonl`：`{date, time, card, reaction}`。`pool` 读它算上次推送。 |
| `slot [--date YYYY-MM-DD]` | 今天的发送时段：按日期做种子的确定性随机（同一天多次运行结果一致），给出时段、窗口、窗口内建议时刻、此刻是否在窗口内。 |

### pool 打分

```
score = 6（卡片被最新摘要「正在想的／悬而未决」直接引用）
      + 3 × 与这两节共享的 [[链接]] 数
      + 0.3 × 共享稀有关键词数（上限 20；二字词，且在全部闪念中出现率 ≤15%）
      + min(搁置天数, 60) / 10
      − 10（7 天内推送过）
```

`score_detail` 给出各项，`shared_links`／`shared_keywords` 便于判断。

### external 输出结构

- `weread.recent_books`：窗口内读过的书（最近阅读日、是否读完）
- `weread.recent_notes`：窗口内新增的划线／想法
- `weread.recent_book_notes`：窗口内在读的书里的**全部旧笔记**（每本最多 20 条）——满分样稿里“五个月前你读《精益商业思维》写过一句”就来自这里
- `weread.latest_note_books`：最近有笔记的 5 本书
- `getnote`：窗口内得到大脑笔记（标题、类型、标签、链接、正文前 800 字）
- `errors`：失败项

### slot 规则

- 工作日：周一至周五，加大小周的上班周六——以 2026-10-17（周六上班）为锚，隔周交替（10-24 休、10-31 上…）。
- 工作日时段：午间 12:00–13:00／下班路上 17:40–18:30／晚上 20:00–21:30。
- 休息日时段：上午晚些 10:00–11:30／下午 15:00–16:30／晚上 20:00–21:30。

## 每日流程（建议）

```bash
python3 工具/推送素材.py slot                 # inside_window=false 就不推
python3 工具/推送素材.py external             # 刷新外部素材
python3 工具/推送素材.py scan --by name       # 近期记录
python3 工具/推送素材.py pool                 # 候选 top 3，苏格挑一张
python3 工具/推送素材.py context "<卡片>"     # 写第一条消息的上下文
# 推送后、拿到反应时：
python3 工具/推送素材.py log "<卡片>" --reaction "接着聊了／没回／……"
```
