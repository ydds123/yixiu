# 其他记录对象说明

本文件只保留尚未归入核心 Skill 的外部来源、有意思与行动说明。原始思考记录、闪念和永久卡片的定义、状态、关系与保存要求，直接维护在 [捕捉 Skill](../.codex/skills/goodidea-capture/SKILL.md) 和 [辨析 Skill](../.codex/skills/goodidea-distill/SKILL.md) 内，本文件不保留副本。

## 保存边界

- 只保存真实存在的信息，没有的信息省略，不为字段完整而猜测。
- 外部材料不自动代表用户立场，建议或想法不自动成为行动承诺。

## 外部来源

外部来源保存带有出处的外部材料，回答“外部世界说过什么”，不表示用户已经形成认识。

- 最少保存标题、原始链接或文件名，以及实际取得的内容。
- 作者、发布日期等信息只有在能够可靠确定时才保存；不能确定时省略。
- 内容缺失、截断或附件未取得且会影响理解时，才说明异常；不记录无助于理解的抓取过程。
- 明显是同一份材料时复用既有记录；无法可靠判断时不猜测合并。

正式入口：用户明确要求保存实际外部材料。

## 有意思

有意思保存用户明确认为值得留下、以后可能继续了解或判断，但尚未认领为闪念、永久卡片，也不要求完整保存来源的内容。

- 至少保存“是什么”；保存动机、链接和情境只在真实存在时保留。
- 它不表示用户已经形成判断，也不等于外部来源的完整快照。
- 只有真实处理结果发生后才增加 `去向`；没有结果时不写“待处理”占位。

正式入口：用户明确表示某个内容有意思、值得留下以后再看，或要求保存为有意思。

## 行动

行动保存用户已经决定在现实中推进或完成的一件具体事情。想法、可选方向、外部材料中的建议和 Agent 推断都不是行动承诺。

- 一份记录只承载一项可以独立推进或完成的行动，至少写清要做什么。
- 对象、完成标准、期限、原因和执行信息只保留用户实际表达过或执行确实需要的部分。
- `status` 允许值为 `待完成`、`已完成`、`已取消`、`已过期`；新建行动默认为 `待完成`。
- 只有实际完成、取消或窗口结束等事件发生后才更新状态，并在需要时记录真实结果。
- 期限不等于已经设置提醒；只有提醒确实创建成功时才能声称存在提醒。

正式入口：用户明确要求把一件事记为行动、待办或任务，或者明确要求改变既有行动。
